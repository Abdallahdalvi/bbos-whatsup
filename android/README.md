# Q20 Messenger

Native Java Android messenger for the BlackBerry 10 Android Runtime (API 18). The rebuilt source uses WhatsApp-inspired XML home and conversation screens, local SQLite history, paged v2 sync, and the supplied Nokia4Ever singleton WhatsApp Web server.

Build from the command line with `build_apk.sh` or `build_apk.ps1`. The debug-signed APK is written to `output/Q20Messenger.apk`.

The server v2 patch is separate and has not been deployed. Read `API_DOCUMENTATION.md`, `INSTALLATION.md`, `HISTORY_IMPORT_REPORT.md` and `TEST_REPORT.md` before connecting. Live server row counts and Q20 runtime behavior remain unverified.
